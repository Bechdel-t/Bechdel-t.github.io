# Software Design & Engineering Artifacts

This folder contains the core refactored source files for the **Travlr Getaways** application, highlighting the transition into a decoupled MEAN stack architecture, modular routing, and JWT-based authentication security.

* **app.js**: Application entry point and middleware configuration.
* **authentication.js**: JWT configuration and middleware protecting secure endpoints.
* **index.js**: Modularized API route definitions.
* **trips.js**: Controller logic managing trip data and CRUD operations.
