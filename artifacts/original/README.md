# Original Artifact Baseline

This folder contains the baseline, pre-refactored version of the Travlr Getaways application source files before implementing full-stack optimizations, database schema definitions, and algorithmic enhancements.

* **app.js**: The initial application entry point and server setup.
* **authentication.js**: The initial authentication configuration module.
* **db.js**: The baseline database connection handler.
* **index.js**: The initial main routing file.
* **travlr.js**: The initial data model configuration.
* **trip-data.service.ts**: The baseline client-side data service.
* **trips.js**: The initial route handler before integrating Mongoose ODM and query filtering.
